## 📱 Application Cards

Each application card shows:
- **Icon** - Large emoji icon with glow effect
- **Title** - Application name (uppercase)
- **Description** - What the app does
- **Badge** - Status indicator (Featured, Integrated, etc.)

### Card Features
- **Hover Effect** - Glows and lifts on hover
- **Click to Launch** - Opens application or shows info
- **Cyberpunk Theme** - Neon cyan with glassmorphism
